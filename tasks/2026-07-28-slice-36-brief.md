## 3D — lexicon schema + seed lexicon

`tools/ajami-pipeline/lexicon/schema.mjs` (+ JSON Schema if useful) and
`tools/ajami-pipeline/lexicon/seed-lexicon.json`.

Entry shape (minimum):
```json
{
  "boko": "string",
  "normalizedBoko": "string",
  "tokens": [],
  "ajami": "string",
  "ajamiCodepoints": [],
  "pronunciation": null,
  "vowelLength": null,
  "category": "native_hausa",
  "orthography": "warsh_kano_ajamix_v1",
  "status": "provisional",
  "confidence": "unreviewed",
  "source": [],
  "reviewer": null,
  "reviewDate": null,
  "notes": ""
}
```

Allowed `status` values exactly: `candidate`, `provisional`, `rule_verified`, `human_reviewed`,
`approved`, `ambiguous`, `blocked`, `deprecated`.

Hard requirements:
- A validator function that **rejects** any entry with `status: "approved"` lacking a non-empty `source`
  **and** a `reviewer` + `reviewDate`. Generated entries must not be able to reach `approved`.
- Seed lexicon must be **`candidate`/`provisional` only** — zero `approved` entries.
- Round-trip test: schema validation catches each malformed case (missing field, bad status, illegal
  promotion).

## 3E — candidate corpus extractor (NOT a gold corpus)

`tools/ajami-pipeline/extract-candidates.mjs` → `data/candidate-corpus.json`.

Extract a representative set from real `app/content.json` covering: common function words; common verbs;
common nouns; curriculum terminology; **words containing every fixed special consonant** (ɓ ɗ ƙ ƴ c ts sh
f n k y); apostrophe-`y`; genuine glottal-stop candidates; morpheme-boundary candidates;
quotation-heavy audioScript examples; short/long vowel ambiguity; `ai` and `au`; word-initial vowels;
word-final vowels; native Hausa `h`; Arabic/Islamic lexical `h`; proper nouns; acronyms; numerals;
mixed Hausa–Arabic; mixed Hausa–English.

Each candidate preserves: source file · field path · **complete surrounding sentence** · normalized Boko ·
proposed tokenization · provisional Ajami · unresolved decisions · confidence · review status.

Deduplicate identical words **without losing context references** (keep an array of occurrences).

Explicitly label the output as candidate material, not gold-standard, in the file itself.

## 3F — Unicode hygiene validator

`tools/ajami-pipeline/validate-unicode.mjs`. Must detect:

Arabic Presentation Forms (U+FB50–U+FEFF) · Private Use Area · replacement chars (U+FFFD) · **stray Latin
letters carrying Arabic combining marks** · combining marks without a valid base · invalid combining-mark
order · mixed canonical/noncanonical forms inside one native-Hausa output · **`U+06D1` in newly generated
AJAMIX text** · unconditional `ه` output for native Hausa · unconverted Boko special letters ·
unconverted apostrophe-`y` · constructed triple-dot substitutes (base letter + U+06DB) · unsupported
extended glyphs · normalization instability (NFC round-trip).

Report per finding: file · field · string · **code-point sequence** · rule violated · recommended
disposition. **Never silently rewrite source content during validation.**

Run it read-only across live `content.json` and report what it finds. Two defects are already known and
must be detected as a self-test of the validator: `pn-maths-01.topicAjami` contains presentation forms
(U+FEDB, U+FECF, U+FED3, U+FBAD, U+FEE3); `V08`'s stored Ajami contains a Latin "V" + fatha (U+064E).

## 3G — font and rendering probe

`tools/ajami-pipeline/font-probe.mjs` + `data/font-probe-report.json` + an HTML probe page
`tools/ajami-pipeline/font-probe.html`.

Target characters:
```
ݑ ط ث ک ࢼ ࢻ ڟ ࢽ ی ؿ ح ه ݣ ࣃ ࣄ
```

Static analysis: attempt to determine glyph coverage in `app/fonts/NotoNaskhArabic-Regular.woff2` by
parsing its `cmap`. **Be realistic** — WOFF2 uses Brotli plus table transforms and this may not be
feasible in pure Node without dependencies. **If you cannot parse it, say so explicitly and clearly; do
not guess, and do not claim coverage you did not verify.** Report exactly what was and was not
determinable.

The HTML probe page must render, for each target character: isolated / initial / medial / final forms,
plus combining-mark placement (sukūn U+0652, shadda U+0651, short-e U+065C), using the actual shipped
font with a visible fallback indicator (e.g. render each char in the Ajami font and in a
deliberately-missing-font control so tofu/.notdef is visually obvious). Claude will render this page in a
browser to complete the visual verification you cannot do headlessly.

**Do not substitute a different code point to work around a missing glyph.** If a glyph is missing, that
is a font/fallback architecture finding, not a mapping change.
