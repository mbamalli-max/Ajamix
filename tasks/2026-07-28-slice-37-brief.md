## Governing decisions (normative — do not deviate)

- **Harmattan is the primary and authoritative font for Hausa Ajami.** Noto Naskh Arabic remains primary
  for **Arabic/Qur'anic** spans and is Hausa's secondary fallback only.
- **A Hausa Ajami word must be shaped as one coherent Harmattan font run.** Do NOT architect Harmattan as
  a five-glyph patch behind Noto — that would assemble single words from two fonts with mismatched
  strokes, dots, baselines, widths and mark positioning.
- Language classes are distinct:
  - Hausa Ajami → `lang="ha-Arab"` `dir="rtl"`, `font-family: "AJAMIX Harmattan", "Noto Naskh Arabic", serif`
  - Arabic/Qur'anic → `lang="ar"` `dir="rtl"`, `font-family: "Noto Naskh Arabic", "AJAMIX Harmattan", serif`
- **Test stock Harmattan first.** Do NOT run TypeTuner, alter OpenType features, modify glyphs, rename the
  family, subset, or strip tables. If stock renders the approved forms correctly, use it unchanged. If a
  specific glyph needs a regional variant, document the exact character, the exact OpenType feature, both
  forms side by side, and why — then STOP and report rather than customizing.
- **No subsetting during qualification** — Arabic subsetting can silently destroy GSUB/GPOS, anchors,
  joining forms and variants. Size optimization is subordinate to correct rendering, and is a later slice.
- **Never substitute a different code point to work around a rendering problem.**

patterns (replace `X`):

```
X        بX       Xب       بXب
بَXَـ     بXْ      بXّ       بXٜ
```

Cover: isolated / initial / medial / final forms · joining to common preceding and following consonants ·
fatha · kasra · damma · short-`e` dot below (U+065C) · sukūn · shadda · shadda+vowel · dagger alif ·
long-vowel sequences · `ai` · `au` · word-initial carriers · stacked/adjacent marks.

Record per test: input code-point sequence · output glyph IDs · advances · offsets · and **explicit
detection of `.notdef`/glyph-ID-0 or missing-mark-anchor failures**. A test that "renders something" is
not a pass — assert no `.notdef` and that marks receive non-zero, plausible anchor offsets.
