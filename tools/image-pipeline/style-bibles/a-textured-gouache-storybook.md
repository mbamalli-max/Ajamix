# A — Textured gouache storybook

**Shared comparison subject:** manifest `p2-bsci-16`, *What Plants Need to Grow*: a potted bean plant, four visually distinct cues for water, air, sunlight, and soil, and one child gently checking soil without pulling any leaf or stem. Required Latin Hausa overlay strings are `Ruwa`, `Iska`, `Hasken Rana`, `Ƙasa`. Use the recurring cast in [characters.md](characters.md): Amina observes; no other cast member is needed.

| Direction | Definition |
|---|---|
| Palette | sun-warmed cream, indigo shadow, leaf green, soil umber, faded coral, small marigold highlights |
| Texture | visibly dry-brush gouache grain, soft paper tooth, slightly imperfect painted edges; texture stays behind focal forms |
| Lighting | late-morning warm window/sunlight, broad soft shadows, no dramatic glare |
| Line treatment | sparse deep-indigo painted contour only where it resolves a silhouette; no uniform cartoon outline |
| Background detail | a calm classroom sill or courtyard edge, 15–20% detail density; broad quiet negative space retained |
| Characters | warm, expressive and believable; layered cotton uniform fabric and subtle hand-painted faces |
| Objects | chunky, readable shapes with convincing paint layering; watering can and pot are tactile but not photoreal |
| Science diagram | objects are illustrative evidence, with clean callout anchors added only in the overlay layer |
| Label-safe area | reserve the upper-left 30% and lower-right 20% as low-detail fields; never paint text or arrows into art |
| Cultural setting | Northern Nigerian school/courtyard materials, locally plausible pot, cotton school uniform, dry-season light and vegetation as relevant |
| Prohibited | generated text, watermark, branding, photorealism, flat-vector finish, exaggerated ethnic features, pseudo-African decorative clichés, cluttered labels |

## Prompt template

`Premium textured gouache children’s editorial illustration, landscape 3:2. [SCENE]. Warm storybook composition with a single clear focal hierarchy, clean silhouettes, soft paper grain, dry-brush gouache edges, Northern Nigerian setting details that are relevant and accurate, believable primary-school child from the AJAMIX recurring-character guide [CHARACTER], broad clean label-safe negative space at upper left and lower right. No text in the artwork; labels will be composited later.`

## Negative-prompt template

`No words, letters, numbers, watermark, logo, branding, photorealism, glossy 3D render, flat generic vector art, busy background, decorative tribal motifs, exaggerated facial features, unsafe child behavior, distorted hands, broken plant, or label/callout graphics.`
