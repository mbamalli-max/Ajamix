# C — Soft digital-paint editorial with restrained dimensional lighting

**Shared comparison subject:** manifest `p2-bsci-16`, *What Plants Need to Grow*: a potted bean plant, four visually distinct cues for water, air, sunlight, and soil, and one child gently checking soil without pulling any leaf or stem. Required Latin Hausa overlay strings are `Ruwa`, `Iska`, `Hasken Rana`, `Ƙasa`. Use the recurring cast in [characters.md](characters.md): Amina observes; no other cast member is needed.

| Direction | Definition |
|---|---|
| Palette | warm sand, muted sky blue, deep botanical green, cacao brown, apricot, restrained electric-blue only for small science cue |
| Texture | soft digital brush with a fine matte grain; smoother planes than A/B but never plastic or glossy |
| Lighting | one gentle directional sun/window key, soft occlusion beneath pot and leaves, carefully restrained depth |
| Line treatment | mostly shape-defined edges; occasional narrow dark edge at focal overlaps only |
| Background detail | softly defocused but painted classroom/courtyard geometry at 15% density; objects stay clearly readable |
| Characters | expressive, believable children with subtle volume and culturally accurate dress; no cinematic glamour |
| Objects | simple volumes, accurate leaf/pot/watering-can construction, soft matte materials |
| Science diagram | illustrative scene with distinct evidence props, compositing anchors left clear rather than generated |
| Label-safe area | reserve a calm light panel of negative space at upper-left and a quiet lower-right quadrant; no high-contrast texture there |
| Cultural setting | Northern Nigerian light, architecture/materials, dress and growing context depicted naturally and only when relevant |
| Prohibited | generated text, watermark, branding, photorealism, glossy 3D/CGI, generic flat-vector appearance, exaggerated ethnic features, pseudo-African clichés, lens flare |

## Prompt template

`Soft digital-paint editorial illustration for a premium primary curriculum, landscape 3:2. [SCENE]. Matte brushwork, restrained dimensional daylight, gentle occlusion, clean readable silhouettes, warm storybook composition, culturally specific Northern Nigerian setting, AJAMIX recurring character [CHARACTER], low-detail upper-left and lower-right label-safe negative space. Artwork contains no text, labels, numbers, arrows, watermark, or brand.`

## Negative-prompt template

`No words, text, lettering, numbers, watermark, logo, branding, photorealism, glossy CGI, dramatic cinematic lighting, generic vector icons, decorative stereotypes, exaggerated faces, clutter, unsafe child behavior, damaged plant, distorted hands, or generated diagram labels.`
