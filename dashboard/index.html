Free-tier usage warning

Vercel and Supabase free tiers are enough for a small pilot, but they do have real limits. Watch Vercel function invocations, bandwidth, and build usage, and watch Supabase database size, row growth, and egress. Review both dashboards at least once per month so the pilot does not silently run into a quota cliff.
